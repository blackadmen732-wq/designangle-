Interaction recipes

Each one is its own page and works with any look. Try them; switch the motion personality to feel the difference.

Calm: a little slower, travels less, never overshoots, for tools used all day. Lively: quicker, travels further, settles with a slight spring, for rare moments and playful brands. Turn on "reduce motion" in your system and movement stops; only gentle fades stay.

Under each one: what does the work. Native means the browser itself; Floating UI and AutoAnimate are small open-source libraries (MIT). Our own code is used only where nothing existing fits.
