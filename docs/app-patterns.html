How those app redesigns actually work

Eight patterns, pulled frame by frame out of two app redesign walkthroughs and rebuilt here in plain CSS. None of them is difficult. What makes the screens look expensive is that all eight are applied together, and nothing else is.

Every demo below is live, not a picture. Resize the window, press the buttons.

01

The action row

The single most copied thing in both redesigns, and the one that does the most work.

One filled pill, then circles. The primary action is the only thing with a solid fill. Everything beside it is a translucent circle with an icon and no label.

They are the same height. This is the detail people miss. The pill and the circles are both 56px, so they sit on one baseline and read as one object rather than three controls that happen to be near each other.

The fill is the only bright colour on the screen. Green on one, white on the other. Use it here and almost nowhere else.

/* same height is what makes the row look designed */
.pill { height: 56px; border-radius: 999px; padding-inline: 34px }
.circ { width: 56px; height: 56px; border-radius: 50%;
        background: rgba(255,255,255,.11) }
02

The glow behind everything

What you are seeing as a "blurry background". It is one radial gradient.

the same card, with a stronger glow

A flat dark screen looks like a switched-off television. One large, very soft radial gradient from the top makes it look lit.

On the Netflix screen the glow is the trailer still itself, blurred and darkened behind the content. On Spotify it is a plain gradient. Same effect, different source.

Keep it weak. 7% to 14% white, spread across more than the whole element. If you can see where it stops, it is too strong.

background-image: radial-gradient(
  120% 90% at 50% 0%,
  rgba(255,255,255,.07), transparent 60%);
03

Hierarchy without changing size

Two lines, the same size, one of them quiet.

Good evening
Pick up where you left off
Jump into a session based on your tastes
Start listening

"Good evening" and "Pick up where you left off" are the same size and weight. The second is simply a lower value grey. That is the whole trick, and it reads as more considered than making the second line smaller.

The second pair inverts it: a small grey line above a larger white one. The quiet line sets up the loud one.

Three text values, not three sizes. White, mid grey, dim grey. Reach for colour before you reach for size.

--ink:   #ffffff  /* the thing itself */
--ink-2: #a8a8a8  /* same size, quieter */
--ink-3: #968d8d  /* labels, captions */
04

Pills, filters and tags

Three sizes of the same idea. None of them has a border.

TV MA HD Subtitles Audio description

Selected inverts, it does not outline. The chosen filter goes solid white with black text. The others are 10% white. No borders anywhere.

Tags are the same thing, smaller and squarer. 10% white fill, 7px radius, grey text. They are information, not controls, so they never look pressable.

A translucent fill beats a solid grey. It picks up whatever is behind it, so the same pill works over a photo or over the page.

.filter        { background: rgba(255,255,255,.10) }
.filter[aria-pressed="true"]
               { background: #fff; color: #000 }
05

Cards separated by value

No border. No shadow. Just lighter than what is behind it.

Episode

Ana Gasteyer

Good Hang with Amy Poehler

Page #070707, card #1c1c1c. That difference alone separates them. Adding a border or a shadow on top makes it look like a web page from 2014.

The artwork is square and sits flush to the card's padding on three sides, with its own smaller radius. Rounding inside rounding: the inner radius is always smaller than the outer.

The action row repeats at a smaller size. 38px circles, 38px pill, same shapes as the big row. One vocabulary, two scales.

/* inner radius < outer radius, always */
.media-card { border-radius: 18px; padding: 14px }
.art        { border-radius: 11px }

Never fit the row neatly. The fourth card is deliberately half off the screen. A row that ends flush looks finished, so nobody swipes it.

Negative margin, matching padding. The scroller runs edge to edge while the cards keep the page's gutter.

No arrows, no dots, no scrollbar. The cut card does the whole job.

.bleed { margin-inline: -22px; padding-inline: 22px;
         overflow-x: auto; scrollbar-width: none }
07

Navigation that floats

A bar locked to the bottom edge is the default. Lifting it off is the choice.

Home
Search
Library

A pill with air around it. Translucent, blurred, floating above the bottom edge instead of welded to it.

The active tab gets its own pill inside the bar, rather than just turning a different colour.

Create is a separate white circle. Cramming it in as a fifth tab is what every default does. Pulling it out makes it the one obvious action.

.nav-pill { background: rgba(255,255,255,.07);
            border-radius: 999px;
            backdrop-filter: blur(16px) }

Media is full-bleed, text keeps its gutter. The image touches every edge; the words stay inset. That one contrast is most of what makes a screen feel native rather than like a web page in a phone frame.

The gradient is the readability. It fades from the card's own colour at the bottom to nothing at 72%, so the text sits on solid ground without a box behind it.

Netflix red appears exactly once on this screen: a 3px underline on the active tab. Not the Play button, not the tags, not the headings. That restraint is why it still reads as Netflix.

background: linear-gradient(to top,
  #121212 4%, rgba(18,18,18,.5) 42%, transparent 72%);
—

What is not here

No animation library, no 3D, no gradient mesh, no glassmorphism beyond one backdrop blur on the nav. Nothing in these screens needs anything you do not already have. The work is choosing one bright colour and spending it once, making the important thing much larger than feels comfortable, and deleting whatever competes with it.

Rebuilt from two app redesign walkthroughs, frame by frame. Colours and shapes are measured from the recordings; the code is written from scratch.
