The real rule

It is about what the bar carries, not the colour behind it.

Anchor a bar that summarises what is above it — a total, a count, a selection. A total that floats is detached from the list it totals. Float a bar that only moves you between places; it is a control panel, not part of the page.

Both redesigns that float also pull the create action out as a separate circle rather than cramming it in as a fifth tab. Spotify does it on dark, Uber Eats on light.

Two more claims the videos corrected

Was wrong

"Dark means sparse, light means dense."

The whole docs split assumed it. The Google Maps redesign is dark and dense — a rating box, an open-status box, four icon actions, a five-tab row and a ticket card, all on near-black.

The axis was never light against dark. It is sparse against dense, and the two are independent. A media screen is sparse because it has one job, not because it is dark.

Too strict

"Exactly one filled button per screen."

The Starbucks redesign has a filled Redeem button on every reward card in a scrolling row. Four visible at once.

The rule holds for screen-level decisions: one primary action answering "what now". A repeated action belonging to each item in a list is a different class and does not count against it.

New

Centred body text is the tell, not centred headings.

Every one of the six redesigns left-aligns what the original centred. The kit's generated-design list names "a centred hero" but not this, which is the more common version of the same mistake.

Method. Nine frames per clip, evenly spaced across the full running time, tiled and read at size. That is a visual review of stills: it catches layout, hierarchy, colour and the before-and-after, and it does not catch timing, easing or anything said aloud. Where a motion number appears anywhere in this repo, it came from a published package, not from these frames.

What this cost. The clips were available from the start. Three documented rules were wrong in the meantime, one of them written and shipped the day before. Reference material that is not opened is not reference.
