# Research behind the kit

Two reports from November 2026 on how professional studios build, and sell, animated
websites. The design rules in `DESIGN.md` come from these.

- **01** — the overall picture: the design process, the animation stack, free sources for
  premium visuals, the design rules, AI agent tooling, and what a $10K project includes.
- **02** — deeper detail: teardowns of award-winning restaurant sites, a learning map of
  tutorials for each effect with exact easing values, studio team sizes and budgets, and
  how $10K+ projects are packaged and priced.

Both reports state their own limits. Prices and library versions move, so re-check any
figure at its source before quoting it to a client.
