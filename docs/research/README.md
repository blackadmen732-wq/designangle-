# Research behind the kit

Two reports from November 2026 on how professional studios build, and sell, animated
websites. The design rules in `DESIGN.md` come from these.

- **01** — the overall picture: the design process, the animation stack, free sources for
  premium visuals, the design rules, AI agent tooling, and what a $10K project includes.
- **02** — deeper detail: teardowns of award-winning restaurant sites, a learning map of
  tutorials for each effect with exact easing values, studio team sizes and budgets, and
  how $10K+ projects are packaged and priced.

**marketplace-app-patterns.md** (Nov 2026) — what the delivery and marketplace
apps actually publish. Real token values extracted from the companies' own
packages: Uber's Base from `baseui@18.2.0` and Material 3 from
`@material/web@2.5.0`. Uber green `#06C167` is verified against the package
source, not quoted from a blog.

Read its tags. Every claim is marked PUBLISHED, OBSERVED or DERIVED, and the
difference matters: Airbnb publishes no design system at all, so every
"Airbnb DLS" value in circulation is somebody's observation. Its screenshot
sections could not be re-verified, because both screenshot tools ran out of
quota mid-task.

**motion-sources.md** (Nov 2026) — the motion rules behind the app style and
`tools/motion.js`: Emil Kowalski's animation skills, ibelick's ui-skills,
Vercel's interface guidelines, Apple's fluid-interfaces talk and the
auto-animate library, each marked KEPT, CHECKED or LEFT with the reason.

Both earlier reports state their own limits. Prices and library versions move, so re-check any
figure at its source before quoting it to a client.
